### About

I build backend systems and AI-powered automation — from async APIs and data pipelines
to real-time voice agents and computer-vision services.

- **4+ years** of production Python: CRMs, payment platforms, high-load APIs and Telegram bots
- **AI focus:** LLM agents, speech-to-text and voice AI, video and audio analysis
- **Architecture:** microservices, event-driven pipelines, async task queues, clean code
- **Based in Ukraine** · open to remote work and collaboration
